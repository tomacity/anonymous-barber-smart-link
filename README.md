# Anonymous Barber Smart Link

Custom Zisto Smart Link demo for **Anonymous Barber Shop**.

## GitHub Pages

Publish this repository from **Settings → Pages → Deploy from a branch → main / root**.

The live URL will be:

`https://tomacity.github.io/anonymous-barber-smart-link/`

## Zisto booking integration

The Smart Link reads configuration from the URL:

```
?project_key=YOUR_PROJECT_KEY&api=https://preview.zisto.app
```

- `project_key`: the connected-project key generated by Zisto.
- `api`: Zisto base URL. Use the Preview URL while testing, then remove/change it to production after the booking API is merged.

Example:

```
https://tomacity.github.io/anonymous-barber-smart-link/?project_key=abc123&api=https://preview.zisto.app
```

Booking flow:

1. Customer taps/scans NFC.
2. Smart Link loads services, staff and availability from Zisto.
3. Customer selects service, barber, date and time.
4. Smart Link posts the booking to Zisto.
5. The appointment appears automatically in the business dashboard.

No Supabase keys or secrets are stored in this repository.
